## Past Assignments

- **[iot-api-sensor](https://github.com/B134x/iot-api-sensor)**: an ESP32 paired with a DHT11 sensor sends temperature and humidity to a Node.js API. Every push to `main` builds the Docker image through GitHub Actions, and the image runs on Kubernetes (Minikube).
- **[Mobile-IoT-Praktikum-3](https://github.com/B134x/Mobile-IoT-Praktikum-3)**: a Flutter app and ESP32 firmware that control an LED and read a DHT22 sensor over BLE and MQTT. It charts the last 20 temperatures and measures latency on both links.
- **[flutterchain](https://github.com/B134x/flutterchain)**: a Flutter Android app and a Solidity contract that log IoT lab equipment loans on the Ethereum Sepolia testnet. The app rejects any other chain.
- **[kasirius](https://github.com/B134x/kasirius)**: a web-based cashier system integrated with the warehouse, built with Laravel.
